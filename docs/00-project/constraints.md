# Constraints

- The assignment must remain within the required technology stack.
- Deployment cost should remain free where feasible.
- MySQL must not be replaced without explicit approval.
- Implementation must remain understandable to future maintainers.
- The repository must support human and AI maintenance.
- Production secrets must remain outside Git.
- Each implementation phase requires verification.
- No application requirement may be invented merely to continue development.

## UI Design Source

Google Stitch is the visual UI reference source for the project.

- Architecture and functionality are defined in repository documentation.
- Visual design will be based on Stitch output.
- Claude must not independently redesign approved Stitch screens without a functional reason.
- Stitch output must not override security, data integrity or business rules.
