# Architecture Decision Records

Use ADRs for important irreversible or expensive decisions. Do not create speculative ADRs.

## Format

```text
# ADR-XXXX — Title

Status:
PROPOSED / ACCEPTED / SUPERSEDED

## Context

## Decision

## Alternatives

## Consequences

## Verification
```
